# 🚀 SmartBookmark

A modern, private, real-time bookmark manager built with **Next.js (App Router)** and **Supabase**.

Users can securely log in with Google, add and delete bookmarks, and see updates reflected instantly across multiple tabs — all while keeping their data completely private.

## 🧠 What This Project Does

SmartBookmark allows users to:

- 🔐 Sign in using **Google OAuth**
- ➕ Add bookmarks (title + URL)
- ❌ Delete their own bookmarks
- ⚡ See updates in real-time (no refresh needed)
- 🔒 Keep bookmarks private per user

Each user's data is isolated using **Row Level Security (RLS)**.

---

## 🛠️ Tech Stack

- **Next.js (App Router)**
- **Supabase**
  - Authentication (Google OAuth)
  - PostgreSQL Database
  - Row Level Security (RLS)
  - Realtime (WebSockets)
- **Tailwind CSS**
- **Vercel (Deployment)**
